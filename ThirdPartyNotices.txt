Viridis color map
Authors: Nathaniel J. Smith, Stefan van der Walt, Eric Firing.
Source: https://github.com/BIDS/colormap/blob/master/colormaps.py
The original file and color maps are released under CC0 / public domain:
https://creativecommons.org/publicdomain/zero/1.0/
This application uses the original 256 Viridis samples rounded to 8-bit RGB.

licenses and third-party notices. The release builder copies those texts from

Sample data
The public sample generator and its synthetic output are covered by the project
MIT license. Measured files originally provided with the programming assignment
are not part of this source snapshot or covered by this license grant.

Vendor format interoperability:
The import readers use documented file-layout facts; no external parser library is bundled.
Reference documentation: https://rainbow-api.readthedocs.io/ and https://ethanbass.github.io/chromConverter/ .
Public validation datasets from rainbow and chromConverterExtraTests are used locally only and are not distributed with DADViewer.
